# Cong Liu's personal website

Static personal website for Cong Liu at UC Riverside.

Website: https://cong2mars.github.io/

## Files

- `index.html`: homepage
- `publications.html`: full publication list
- `style.css`: site styling
- `favicon.svg`: favicon
- `assets/portrait.jpg`: profile photograph

## Publishing

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Edit the HTML or CSS files and commit to `main` to update the published site. No build step is required.
